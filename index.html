ToDoボード プライバシーポリシー

制定日: 2026年10月6日

ToDoボード（Windows版・Android版、以下「本アプリ」）は、カードを列に並べてやることを管理する個人用のアプリです。 本アプリが扱う情報と、その扱い方を次のとおり定めます。

扱う情報

本アプリが扱うのは、利用者が本アプリに入力したボード・列・カード・ラベル・チェックリスト・アラーム・添付ファイルの情報だけです。 これらは利用者の端末内に保存されます。

Googleドライブの利用

本アプリは、複数の端末で同じ内容を見るために、利用者自身のGoogleドライブを受け渡し場所として使います。 Android版はGoogleアカウントでログインし、Google Drive APIを通じて、マイドライブ内の「ToDoボード同期」フォルダにある同期用ファイルと添付ファイルの写しだけを読み書きします。 それ以外のファイルを読んだり、変更したり、削除したりすることはありません。

ドライブ全体への権限を求めるのは、Windows版がGoogle Drive for desktopを通じて作成した「ToDoボード同期」フォルダを、Android版から開くためです。

外部への送信

本アプリは、利用者のデータを開発者のサーバーやその他の第三者へ送信しません。広告や利用状況の分析も行いません。 データが端末の外へ出るのは、利用者自身のGoogleドライブとの同期だけです。

Google API サービスのユーザーデータに関するポリシー

本アプリがGoogle APIから受け取った情報の使用および他のアプリへの転送は、 Google API Services User Data Policy（Limited Use の要件を含む）に従います。

権限の取り消しとデータの削除

本アプリへのGoogleドライブの権限は、Googleアカウントのサードパーティ アクセスからいつでも取り消せます。 端末内のデータは本アプリを削除すると消えます。Googleドライブ上のデータは「ToDoボード同期」フォルダを削除すると消えます。

改定

このポリシーを変更するときは、このページを更新します。
